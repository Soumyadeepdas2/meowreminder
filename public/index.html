HOW TO USE MEOW

  1. Link this browser: press 🐾 GET THE MEOW, then press Start in Telegram. No Start button (you started the bot before)? Type the code shown on screen into the chat and send it.
  2. One-time reminder: just type it — “call father tomorrow 9am”, “buy milk in 2 hours” — or use the IN 15 MIN / CUSTOM TIME chips.
  3. Every day, same time: tap 🔁 EVERY DAY and pick how often (every day / weekdays / weekend / one specific day) and at what time — or just type it: “every day 9am water plants”, “every saturday 10am gym”. It messages you at that time, every time, until you remove it.
  4. Done / later / never: every reminder has ✓ done, snooze 15m and remove. Marking a repeat done just sends it back to the schedule for its next occurrence.
  5. Private by default: only your Telegram account can see or change your reminders. Same account on any number of browsers = same list, changes sync in seconds.
